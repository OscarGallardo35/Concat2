Cómo se instalan

python scripts/install-templates.py            # las 15
python scripts/install-templates.py --list     # ver el pack
python scripts/install-templates.py plato-del-dia
python scripts/install-templates.py --portable D:/vibecut-portable

Copian a la carpeta de plantillas del editor (%APPDATA%\pro.mercadodigital.vibecut\templates en Windows, el equivalente en macOS y Linux). Después: Inicio › Plantillas.

Las previsualizaciones de esta página se dibujan leyendo el propio template.json: misma fuente, tamaño, color y placa. Las fotos son marcadores con el nombre del slot, no un render del motor.
